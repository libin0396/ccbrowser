# 个人版空间保留与清理

本次只修改日志保留，不自动删除浏览器资料、Cookie、历史、下载或账号数据。

- macOS 默认根目录：`~/Library/Application Support/Fury`；设置 `FURY_HOME` 时以覆盖路径为准。
- `fury.db` 保存环境配置；`profiles/<id>/` 保存该环境 Chromium 用户数据。必须保留以维持资料、Cookie、登录状态。不要将整个根目录当缓存删除。
- `logs/agent.log` 本次改为运行中按事件轮转：当前段最多 4 MiB、上一段 `agent.log.1` 最多 4 MiB（旧版已经生成的超大日志首次迁移除外）。每条事件限制 64 KiB，并追加截断提示。轮转失败时放弃写入，不突破上限；stderr 仍可输出。进程内互斥保护并发事件；多个独立 agent 进程不共用此互斥锁，应避免多个实例写同一个 `FURY_HOME`。
- `FURY_LOG=off` 禁止持久日志。日志可能包含环境名称、时间等隐私，应只保留本地诊断用途。
- 本次不为 Chromium 所有站点存储加硬配额，避免清除登录态。因此浏览器资料仍可能随使用增长，不能声称已为所有数据实现自动上限。
- 优先关闭该环境后，通过现有“清理缓存”功能清理；它拒绝清理运行中的环境，仅处理上游允许的缓存目录。不要选择环境删除/永久清除代替缓存清理。
- `core.bundle` 是内核，`dock.noindex` 是按环境命名的 Dock 副本，不是 Cookie 存储。不要在浏览器运行时清理。
- 开发目录 `target/`、`desktop/node_modules/`、`desktop/dist/` 是可重建产物，不应加入源码交付。清理前停止编译，必要时先归档安装包和测试报告。
- 构建下载内核压缩包可在校验、安装并确认不再需要重建后清理；不要清理对应运行中的内核目录。
- 实际云端占用由主验收报告记录；Mac 用户资料尚未实测，本文件不是实测体积承诺。

日志测试覆盖运行中连续写入超过两个段、保留最新事件、大事件截断、轮转失败拒绝继续追加。未测试 macOS 多进程竞争或强制断电恢复。
